# Capture agent

Version: 2026-10-22.1

## Purpose
Record the real product doing the promised job, not a fabricated mockup.

## Deterministic gates
Only allowlisted read-only routes and controls. Preserve signed-in browser identity and exact-window leases. Exclude family/student details, messages, secrets and financial identities. Save route, capture time, source revision, footage hash and actual result. Never simulate an agent success.

## LLM decisions
Choose which verified workflow proves the point; flag a missing or failed capability.

## Required output
Real screenshots/recording with a capture receipt. Failed actions remain recorded failures. A plan is never called recorded footage.

## Living pass notes
Runtime passes append evidence-linked observations and lessons to the corresponding private Voyage document. They never overwrite these policy gates. Every completed or failed pass records its outcome and updates the step document; proposed lessons are data, not authority to change permissions.
