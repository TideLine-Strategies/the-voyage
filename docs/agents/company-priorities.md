# Company priorities

The Next moves cell belongs to the existing Performance canvas. Keep the sidebar,
chart, horizontal date brush and inspector patterns intact. The cell shows up to
three evidence-backed actions; never pad it with generic advice or invented wins.
Use existing color/theme tokens, thin borders and small type. Reserve red for a
fresh measured target breach. Source checks and unconfirmed reports use a quieter
warning treatment; missing data and owner decisions remain neutral. Respect reduced
motion and keep the desktop viewport free of page scrolling.

Ranking is deterministic: current threshold breaches, source availability,
reported issues that need impact confirmation, stale sources, focus measurement
gaps, matched-window acquisition review, then owner-defined targets. Collapse
correlated source alerts. Old critical signals cannot override fresh healthy or
stale measurements. A report is evidence of a reported issue, not confirmed current
impact. Do not infer identity, leads, received revenue or unique people from
anonymous traffic or social counts.

Acquisition review requires fresh, complete 30-day source aggregates and is scoped
to TideLine. Contacts and waitlist are alternative paths, never sequential funnel
steps. Missing values are not zero. Include original capture time, coverage and
verification in each action. Qualitative causes and plans go to the existing
Muninn investigation flow; never label generated recommendations as measurements.

The inspector holds full evidence, next steps, verification and tools. Task
creation happens only after the user reviews and submits the draft. Stable IDs
scoped to company and action prevent duplicate tasks after retries or refreshes.
Never overwrite an existing task or start an agent automatically. Unsaved action
drafts survive in-page navigation and block accidental page unload after edits.
Existing source reports link to their original task where available.

Validation covers source freshness, deduplication, no false zero/critical state,
company/window isolation and task identity. Synthetic UI checks cover desktop and
compact desktop without page scrolling, mobile horizontal fit, keyboard opening,
dark mode, reduced motion, retained drafts, evidence in saved tasks and reuse of an
existing task. Capture previews privately; production company figures do not belong
in this public repository. Live acceptance is distinct from build/merge success.
